# 💰 Personal Finance API
API REST para gerenciamento financeiro pessoal desenvolvida com Java e Spring Boot.

## 📖 Sobre

A Personal Finance API é uma aplicação Back-End desenvolvida para gerenciamento de receitas, despesas e categorias financeiras.

O objetivo do projeto é aplicar conceitos utilizados no mercado de desenvolvimento Back-End, incluindo:

- Arquitetura em camadas
- APIs REST
- Persistência de dados
- Modelagem de domínio
- Boas práticas com Spring Boot

## ✨ Funcionalidades

- Cadastro de usuários
- Cadastro de categorias
- Cadastro de receitas
- Cadastro de despesas
- Consulta de transações
- Atualização de registros
- Exclusão de registros

## 🛠 Tech Stack

- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- PostgreSQL
- Maven
